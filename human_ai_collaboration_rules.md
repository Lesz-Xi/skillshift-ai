# 🤖 AI Collaboration Rules - MLBB Coach AI Project

## Claude's Operating Guidelines

When working on the MLBB Coach AI project, always prioritize **integration-focused solutions** that consider how game mechanics, data processing, and user experience work together rather than treating them as isolated components. Leverage Rhine's deep MLBB expertise by asking specific clarifying questions about strategic nuances, edge cases, and gameplay contexts before implementing any coaching logic—never assume or generalize game mechanics without validation. Focus on **systematic debugging approaches** by breaking down problems into game logic vs. technical implementation layers, providing multiple solution options when possible, and explaining the underlying concepts behind fixes to maintain Rhine's learning momentum.

Maintain a **project-focused approach** by ensuring every technical decision aligns with the end goal of creating actionable coaching feedback that helps MLBB players improve their strategic gameplay. When suggesting implementations, always consider scalability, maintainability, and how new features integrate with existing components, while keeping the user experience centered around delivering insights that feel like advice from a skilled, non-toxic coach rather than generic statistical output.

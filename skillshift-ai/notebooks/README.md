# 📊 MLBB Coach AI - Data Science Platform

## 🎯 Overview

This directory contains Jupyter notebooks and data science tools for analyzing MLBB gameplay data, experimenting with ML models, and generating insights.

## 📁 Structure

```
notebooks/
├── 01_data_exploration/          # Data exploration and EDA
├── 02_behavioral_analysis/       # Player behavior analysis
├── 03_meta_analysis/             # Meta game analysis
├── 04_model_experiments/         # ML model experiments
├── 05_performance_analysis/      # Performance analytics
├── 06_visualization/             # Data visualization
├── templates/                    # Notebook templates
└── utils/                       # Utility functions
```

## 🚀 Getting Started

1. **Install Dependencies**:

   ```bash
   pip install jupyter pandas numpy matplotlib seaborn scikit-learn plotly
   ```

2. **Start Jupyter Lab**:

   ```bash
   jupyter lab
   ```

3. **Open Example Notebooks**:
   - Start with `01_data_exploration/player_data_overview.ipynb`
   - Explore `02_behavioral_analysis/playstyle_classification.ipynb`
